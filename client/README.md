# Ecommerce Marketplace — Client

React + Vite + Tailwind CSS frontend for the multi-vendor ecommerce marketplace.

## Development

```bash
npm install
npm run dev
```

Set `VITE_API_URL` in `.env` using `.env.example`.

## Production build

```bash
npm run build
npm run preview
```

The frontend is designed to be deployed from the `client` directory.
